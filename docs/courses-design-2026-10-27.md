# 코스·진도 — 반 단위 수업 진행 처리로 회차 묶음 자동 배부 (2026-10-27)

> 요구: "1주차 강의를 진행한 학생에게 복습지·숙제·퀴즈 등을 미리 설정해 두고, 학생마다
> 하나씩 누르지 않아도 전체적으로 쭉 들어가게." 참고 이미지 01 "내 반에 맞춰 자동으로 열리는 강의실".

## 확정 결정 (2026-10-27)
| 항목 | 결정 |
|---|---|
| 배부 트리거 | **반 단위 처리 + 학생 체크** — "○반 1주차 진행" → 반 학생 전원 체크(그날 일일마킹 결석은 자동 해제) → 배부 |
| 숙제 형태 | **체크 항목** — 문구 + 마감(배부일 + N일, KST). 학생이 완료 체크, 원장은 진도 표로 확인 |
| 중간 합류 | **자동 지급 안 함** — 합류 후 회차부터. 지난 회차는 "보강 배부"로 골라서 |

## 구조
```
courses ─┬─ course_groups ── student_groups(반)
         └─ course_sessions(position) ── course_session_items(kind: material|test|drill|guide|homework)
course_session_deliveries (session × student, regular|makeup)  ← 배부 = 1행
course_homework_checks    (item × student)
```

- **배부는 `deliver_course_session()` RPC 하나**(SECURITY DEFINER, 한 트랜잭션)
  1. 권한 검사: `staff_has_permission('courses')`. 담당 범위 밖 학생이 하나라도 섞이면 통째로 거절
  2. 승인된 학생에게만 배부 행 insert. 이미 받은 학생은 건너뜀(멱등)
  3. 새로 받은 학생에게 기존 배정 경로로 넣음: 자료 → `material_assignments`, 시험지 → `test_assignments`(스냅샷)
  4. 알림: 학생과 연결된 학부모에게, **새로 받은 학생분만** 보냄(재처리해도 중복 알림 없음). 제목에 실명은 넣지 않음
- 조교는 `courses` 권한만 있으면 배부할 수 있다(자료·시험 권한이 따로 없어도 됨). 권한 키는 `staff.ts`와 DB CHECK 제약에 같이 추가했다.
- 훈련·가이드는 발행되면 원래 전체에게 공개라, 강의실에서 링크로 묶어 보여 주기만 한다.
- 학생·학부모는 **배부받은 회차만** 볼 수 있다(아직 안 열린 회차는 제목도 안 보임). 판정은 `course_session_visible()`이 한다.
- 회차를 고쳐 저장하면 `sync_course_session_assignments()`가 **이미 받은 학생에게도** 새 자료·시험 배정을 채운다(알림 없음).
  배부 RPC도 같은 함수를 부른다. 회차에서 뺀 항목의 배정은 남는다.
- 항목 행은 id로 갱신한다 — 숙제 문구를 고쳐도 행이 유지돼 학생 완료 체크가 살아남는다.
- `(course_id, position)` 유니크(지연 가능 제약). 순서 바꾸기는 `move_course_session()` 한 트랜잭션 — 중간 상태가 남지 않는다.

## 코드리뷰 반영 (2026-10-27, 마이그레이션 `20261027010000_courses_review_fixes.sql`)
- 배부 RPC 반환이 `{delivered, already, ineligible}`(jsonb) — 이미 받은 학생과 배부 불가(미승인·정지) 학생을 구분해 보여준다.
- 학부모 알림 링크 `/dashboard/class?child=<자녀 id>` — 자녀가 둘이어도 해당 자녀 강의실로 간다.
- 회차 저장 시 자료·시험지·훈련·가이드 id가 **이 교직원 세션으로 읽히는지** 확인한다(시험지는 regular만). definer RPC 앞단 검증.
- 코스 상세는 이 코스가 쓰는 참조만 읽고, 피커 전체·학생 명단은 편집기/배부 시트가 열릴 때 액션으로 읽는다.

## 코드리뷰 2차 반영 (2026-10-27, 마이그레이션 `20261027020000_courses_review_fixes_2.sql`)
- `move_course_session()` RPC, `sync_course_session_assignments()`에 조교 담당 범위 가드.
- 회차 저장: 참조 검증은 **새로 담거나 바뀐 항목만**('courses'만 있는 조교가 원장이 담은 자료 때문에 저장 못 하지 않게).
  일부만 써진 뒤 실패하면 `written`으로 알려 편집기가 닫고 새로 읽는다(id 없는 행으로 재저장 → 중복 방지).
  배정 동기화 실패는 경고로만(저장은 유지). 저장 후 다시 읽기 실패 시 빈 목록을 돌려주지 않는다(다음 저장이 전부 지우던 문제).
- 배부 시트: 명단 도착 전 반을 바꿔도 지금 고른 반으로 기본 체크. 명단 실패 시 "다시 시도".
- 피커 목록은 코스 상세에서 첫 편집기 열 때 한 번만 읽어 모든 회차 카드가 공유.
- 강의실: 회차 메타 조회를 항목·숙제 조회와 병렬로(왕복 4단계 유지).

## 코드리뷰 3차 반영 (2026-10-30, 마이그레이션 `20261030010000_review_fixes_3.sql`)
- 회차 저장은 `save_course_session_items()` 한 트랜잭션(제목·요약·항목 diff, 저장 행 반환). `written` 땜질 제거.
- 배정 동기화 실패 시 "배정 다시 채우기" 버튼(`syncSessionAssignmentsAction`) — 저장 버튼은 비활성이라 따로 둠.
- 배부 시트 기본 체크는 명단 **첫** 도착 때만(배부 뒤 새로 읽어도 손으로 푼 체크 유지). 부모가 넘기는 빈 Map 고정.
- 서버 액션 호출에 `.catch` — 실패 시 "다시 시도"가 뜨게.
- 훈련 결과 알림 수신 조교는 'passages' 권한 보유자만. 탈퇴 시 `drill_attempts.share_note` 파기(처리방침 §6·시행일 2026-10-30).

## 주의
- 회차에 넣은 자료가 **미발행**이면, 배정 행이 있어도 학생에게 보이지 않는다(자료 RLS). 그래서 어드민 편집기에서 경고를 띄운다.
- 배부 취소는 v1 범위 밖이다. 시험 응시 기록이 붙을 수 있어서, 필요하면 자료·시험 화면에서 개별로 배정을 해제한다.
- RLS 공격 시나리오 C0~C9를 실제 학생·학부모 권한으로 검증했다(ROLLBACK).
  - 타인 회차 열람, 안 열린 회차의 숙제 체크, 타인 명의 체크, 배부 위조, 학생·anon의 RPC 호출 → 전부 차단
